# Claude Automation Foundry

Turn one sentence into a browser automation that is inspected against the real site, generated by Claude Opus 5, executed in an isolated Hyperbrowser sandbox, and returned as reusable TypeScript.

## Get an API key

1. Get a Hyperbrowser API key at https://hyperbrowser.ai.
2. Get an Anthropic API key with access to `claude-opus-5`.
3. Create `.env.local`:

```bash
HYPERBROWSER_API_KEY=your_hyperbrowser_key
ANTHROPIC_API_KEY=your_anthropic_key
```

Keys are used only by server-side code and are never sent to the browser.

## Quick start

```bash
npm install
npm run preflight
npm run dev
```

Open http://localhost:3000, describe a web task, and optionally provide its target URL and login credentials.

## How the loop works

1. Validate the task and target URL.
2. Open a Hyperbrowser session and capture the real page structure and screenshot.
3. Give Claude Opus 5 the task and captured selectors.
4. Stream the generated Playwright TypeScript into the UI.
5. Run the script against a fresh Hyperbrowser session inside a `node-chromium` sandbox.
6. If it fails or returns nothing, provide Claude the error and a fresh capture for one repair attempt.
7. Return the real result, final screenshot, token usage, step count, and downloadable script.

Generated model code never runs with `eval` or inside the Next.js process. It is written to a disposable Hyperbrowser sandbox and capped at 90 seconds. Login credentials are supplied only as runtime environment variables; they are not written into generated code or persisted.

## Cost note

The UI calculates model cost from real API token usage using the configured Opus 5 rates of $5 per 1M input tokens and $25 per 1M output tokens. This is model cost only; Hyperbrowser usage is separate.

This growth workflow makes reusable web-data and integration automations fast to demonstrate, share, and adopt.
